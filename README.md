**VOID.rpc** — это мощный и легкий инструмент для полной кастомизации твоего статуса (Rich Presence) в Discord. Никакого лишнего геморроя, консольных окон и сложных конфигов — всё управляется через красивый графический интерфейс.

## <img src="logo.png" width="24" style="vertical-align: middle;" alt="logo"> Система пресетов
Создавай, сохраняй и удаляй неограниченное количество кастомных статусов. Переключайся между ними в один клик.

## <img src="logo.png" width="24" style="vertical-align: middle;" alt="logo"> Цикл пресетов (Слайд-шоу)
Включи автоматическую ротацию статусов по таймеру, превратив свой профиль в живую ленту.

## <img src="logo.png" width="24" style="vertical-align: middle;" alt="logo"> Умная защита прав доступа
Программа автоматически сбрасывает системные ограничения "Только для чтения" с файлов конфигурации. Больше никаких вылетов и вырвиглазных ошибок!

## <img src="logo.png" width="24" style="vertical-align: middle;" alt="logo"> Контроль лимитов
Встроенные интерактивные счётчики символов (до 128) загатятся красным, если ты превысишь ограничения Discord API.

## <img src="logo.png" width="24" style="vertical-align: middle;" alt="logo"> Быстрые действия
Добавлены кнопки мгновенной очистки полей (`×`) и копирования Application ID (`📋`) в буфер обмена.

---

##  Глобальные горячие клавиши (Hotkeys)
Программа отслеживает нажатия, даже если ты находишься в игре или приложение свернуто в трей:
* `Ctrl + Shift + H` — Быстро скрыть окно в системный трей или развернуть обратно.
* `Ctrl + Shift + X` — Мгновенно очистить текущий статус в Discord.
